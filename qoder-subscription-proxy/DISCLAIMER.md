## 首次下载和本地缓存

**首次启用后，Qoder 启动插件的 MCP 服务时会自动准备核心。** 插件优先复用已有校验通过的核心。没有可复用核心时，通过系统 `curl` 和 HTTPS 查询 Magpie 官方最新稳定版，按平台下载并检查 SHA256 后写入 `dataDir/runtimes/`。后续核心下载、版本切换和清理由用户在管理页决定。默认数据目录为 `~/.qoder/qoder-subscription-proxy/data`。同版本有效缓存可直接复用。下载失败可在「订阅代理管理」查看原因并重试；下载、等待其他会话、校验和安装共用 10 分钟预算。主动停止会取消本会话的准备并保留暂停状态，直到用户再次启动。

下载使用 `QODER_HTTP_PROXY` 或 HTTPS/ALL 代理环境变量，均未设置时才检查系统代理；`NO_PROXY` 例外继续生效。下载会访问官方托管服务及其重定向目标，流量可能经过你配置的代理。插件对照所选官方发行版公布的文件大小和 SHA256 校验下载内容。使用自定义 `BRIDGE_BIN` 时，文件来源、兼容性和执行权限由用户确认。

本仓库不复制来源项目的 Git 历史或用户运行数据，第三方文档、原始资产和许可证保持原有归属。

## 私有数据与第三方插件

托管 Magpie 把配置和账号保存在 `dataDir/magpie`，主目录、系统缓存和临时文件均指向本插件的数据目录。默认使用私有客户端设置目录；显式设置 `BRIDGE_QODER_CLIENT` 后，仅向托管核心开放所选 Qoder 客户端的设置，上游启动迁移和原生 Agent 接入都可能写入该目录。插件会校验自己以往保存的核心和凭据。服务商密钥应保存在托管 Magpie 的私有配置中；宿主环境中的服务商密钥不会传给核心。独立 Magpie 使用自己的配置和授权。订阅账号默认关闭，使用前需用户在原生管理页的隐私设置中显式开启并本人登录。托管核心的客户端文件和系统缓存指向插件数据目录，但该开关仍可能读取操作系统凭据存储中的其他客户端条目；不能将私有数据目录视为账号沙箱。不接受这一行为时保持关闭，只使用 API-key 服务商。核心自动更新仍关闭。

所需第三方插件由用户在 Magpie 原生管理页面自行安装和管理，本插件不提供代装工具，也不固定社区插件版本。第三方插件及其运行依赖未随包，安装时可能联网下载，授权与能力以所选插件及服务商为准。使用官方程序不代表个人订阅允许所有第三方主模型集成；插件不承诺隐藏客户端或避免风控。

已有原生模型组不会因升级自动删除。若曾在 Qoder 使用 `group/…` ID，可自行改回原始模型 ID，并在 Magpie 原生管理页管理旧组；插件不会自动修改 Qoder 设置。

GPT 生图走 Magpie 原生 `/v1/images/generations`，插件仅做本地交付适配。旧 Gemini 生图工具完全移除。以上设计与模拟测试不代表真实账号、Desktop 安装或五平台实机已验收。

## 本地安全边界

每个插件数据目录的 `launcher-secrets.json` 保留 `apiKey` 和 `mgmtKey`。`apiKey` 仅用于客户端标识，固定 Magpie 回环模型 API 接受任意 key，不能声称强制 API 认证。模型服务默认使用 `19787/v1`，原生 Web 管理默认使用 `19788`。实际端口以插件管理页显示为准。打开插件管理页会读取本机状态并检查官方更新，下载更新、切换版本和应用新端口均由用户操作。显式打开管理页时，浏览器使用本次核心的实例密钥登录，Magpie 设置 HttpOnly cookie 并清理 URL。核心重启后旧链接与 cookie 失效。运行期间链接和 cookie 均可重复使用，能读取本机数据目录的程序也可能取得管理权限。服务只允许 loopback，禁止共享或通过端口映射、反向代理、隧道对外开放；请将数据目录限制为本人可读。

OAuth token、API Key、日志和生成文件会保存在本机用户数据目录。保护目录权限及备份，不要分享整个数据目录、完整回调 URL 或未脱敏日志。

卸载插件不会自动删除账号数据，也不代表已在服务商侧撤销授权。按需在服务商账号安全页面撤销授权，并自行处理本地凭据及备份。
